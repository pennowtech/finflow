# ADR-007: GUI Framework — PyQt6

## Status
Accepted

## Context
The app needs:
* Native apps for Windows, macOS, Linux
* Complex widgets (tabs, charts, dialogs)
* A polished desktop look
* MVC/MVP support

### Decision
Use **PyQt6** over Tkinter or Kivy.

### Consequences
* Robust widget library
* Well-supported
* Commercial-friendly
* Larger binaries compared to Tkinter
